# Revvo

> Revvo is an AI-powered tire and fleet management platform. Its TireIQ engine turns raw tire-sensor data into pressure, temperature, tread-wear and puncture alerts. The Revvo API lets fleets register gateways and TPMS sensors, manage vehicles and tires, and pull tire events/alerts, all scoped to a fleet. Authentication is a two-step exchange: present a fleet API key to POST /auth to obtain a JWT, then send it as a bearer token.

## Concepts
- Auth: POST /auth with X-API-KEY header returns a JWT; use Authorization: Bearer on all other calls.
- Tenancy: every operation is scoped to a fleet via {fleetId}.
- Core resources: fleet, vehicle (vin/assetId), device (gateway + sensor), tire (by position), event.
- Errors: JSON envelope with success, displayErrorMessage, internalErrorCode (not RFC 9457).
- Events: retrieved by time window (fromTimestamp/toTimestamp), not cursor pagination.
